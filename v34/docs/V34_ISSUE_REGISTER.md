## Verified and found correct (no change needed)
* Inter-branch stock/cash transfers (`f360/v31.php`): tenant and destination/source branch checked on receive/cancel; same 404 for "not yours".
* New restaurants get their own Management/UT/Kitchen/Waiter departments (explicit-id keys are tenant/branch-prefixed by `mt_normalize`).
* Restaurant backup (`f3_db_dump`) contains only that branch's rows and no platform tables.
* Paid overtime is information-only in payroll (`ot_paid_info`), never added to salary payable.
* Conversion refuses the live database without `--owner-approved-live`; staging-isolation check refuses `u245900320_ksdd`.

## Known gaps NOT fixed in V34 (see Go/No-Go)
Support tickets (missing), cross-branch employee transfer (missing: only department/designation history within a branch),
backup-health monitor in Super Admin (missing; `tools/health-check.php` covers the installation), database-level
binding of rows to `p_branches` (rows carry tenant/branch with composite parent/child FKs, but no FK to `p_branches`),
separate restricted MySQL identities for runtime vs migration (not available on Hostinger shared hosting — see report).
